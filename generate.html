📖 Input File Formats
📋 Student List Excel
roll_number student_name
Each row = one student. Extra columns are ignored.
👨‍🏫 Staff / Course Excel
staff_id staff_name subject_code subject_name department section year batch academic_year
Each row = one subject taught by one staff member. Extra columns are ignored.
📊 Output Format
Generated Excel will have these 11 columns (matching Good.xlsx):
department roll_number student_name staff_id staff_name subject_code subject_name section year batch academic_year
Formula: Total rows = Students × Subjects
Example: 60 students × 9 subjects = 540 rows
